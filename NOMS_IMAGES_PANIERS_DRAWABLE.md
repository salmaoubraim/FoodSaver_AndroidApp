# Noms EXACTS des images paniers pour `res/drawable/`

À placer dans **app/src/main/res/drawable/**.  
Règles Android : **uniquement minuscules, chiffres et underscores** (pas d’espaces, pas d’accents).

| Titre / usage      | Nom exact du fichier   |
|--------------------|------------------------|
| Tagine             | `panier_tagine.png`    |
| Pizza              | `panier_pizza.png`     |
| Sandwich           | `panier_sandwich.png`  |
| Petit-déjeuner     | `panier_petit_dejeuner.png` |
| Salade             | `panier_salade.png`    |
| Autre (défaut)     | `panier_autre.png`     |
| Placeholder        | `placeholder_food.png` (déjà présent) |

**Noms à utiliser tels quels** (pour éviter les erreurs de nommage) :
- `panier_tagine`
- `panier_pizza`
- `panier_sandwich`
- `panier_petit_dejeuner`
- `panier_salade`
- `panier_autre`

Formats acceptés : **.png**, **.jpg** ou **.webp**.  
Exemple : `panier_tagine.png` dans `drawable/`.
